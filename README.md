# PICO (피코)

![PICO 공연 티켓 예매 도우미 매칭 플랫폼 배너](assets/pico-banner.png)

**공연·이벤트 티켓을 예매하려는 이용자와 예매를 도와줄 도우미를 연결하는 매칭 플랫폼**

멋쟁이사자처럼 데모데이에서 진행한 팀 프로젝트입니다. 원하는 티켓을 직접 예매하기 어려운 이용자가 도우미를 찾고, 희망 좌석과 예매 성공 조건을 전달한 뒤 결과와 증빙까지 확인할 수 있도록 설계했습니다.

## 주요 흐름

1. **도우미 탐색** — 프로필과 경력 정보를 보고 예매를 맡길 도우미를 찾습니다.
2. **요청 및 조건 합의** — 예매처, 희망 좌석, 성공 조건을 요청서에 담아 보내고 도우미와 최종 조건을 조율합니다.
3. **예매 결과 확인** — 도우미가 등록한 예매 결과와 증빙을 확인합니다. 필요한 경우 문의나 분쟁 절차로 이어집니다.

## 내 기여

### 백엔드 개발

- **회원 계정·도우미 온보딩** · Spring Boot로 회원가입·로그인·계정 복구 API와 도우미 프로필 등록·수정, 심사 신청 API를 구현했습니다.
- **예매 요청·매칭·합의** · 예매 요청 접수부터 도우미 수락, 조건 합의, 결과 확인까지 이어지는 API를 구현했습니다. 결제와 매칭권 상태를 연동하고, 전액 환불 이후 요청과 합의 상태가 다시 변경될 수 있도록 보완했습니다.
- **AWS S3 증빙 업로드** · 도우미 심사와 예매 결과에 필요한 증빙을 S3에 직접 올릴 수 있도록 임시 업로드 URL을 발급했습니다. 관리자 검토를 통과한 증빙은 임시 열람 URL로 접근하도록 구현했습니다.
- **관리자 신고·후기 관리** · 관리자용 신고 조회·처리와 후기 숨김 API를 구현했습니다.
- **공연 데이터·AI 검토 연동** · KOPIS 공연 조회·순위·예매처 링크를 API로 제공했습니다. Liner AI를 연동해 예매 요청 내용을 검토하고, 도우미 프로필·경력 증빙의 사전 심사를 지원했습니다.
- **인기 검색어·최근 매칭 활동** · 별도 백엔드 브랜치에서 인기 검색어 일별 집계 API를 개발하고, 도우미 최근 매칭 시각을 API 응답에 추가했습니다.

### 서비스 기획 및 운영

- **서비스 및 사업모델 기획** · 팀과 함께 티켓 예매가 필요한 이용자와 현업 도우미를 연결하는 서비스의 사업모델을 기획했습니다. 법률 자문에서 나온 쟁점을 팀에 공유하고, 사업모델과 운영 방식을 함께 검토했습니다.
- **현업 도우미 섭외 및 온보딩** · 티켓 예매 분야 현업자를 직접 섭외하고, PICO에서 활동을 시작해 정착할 수 있도록 지원했습니다.
- **법률 자문 도입 및 검토 조율** · 서비스에 법률 검토를 도입하고 자문 일정을 조율했습니다. 이용약관, 개인정보 처리, 연락처 제공 동의 관련 의견서를 팀에 전달해 서비스 운영에 반영할 사항을 검토했습니다.

## 구현 및 데모

팀 프론트엔드는 React, TypeScript, Vite로 구성되며, OpenAPI 명세를 기준으로 백엔드 API와 연동합니다. 개발용 데모 모드에서는 결제와 본인인증 등 일부 단계의 응답을 모의 처리합니다.
