# PICO (피코)

![PICO 공연 티켓 예매 도우미 매칭 플랫폼 배너](assets/pico-banner.png)

**공연·이벤트 티켓을 예매하려는 이용자와 예매를 도와줄 도우미를 연결하는 매칭 플랫폼**

멋쟁이사자처럼 데모데이에서 진행한 팀 프로젝트입니다. 원하는 티켓을 직접 예매하기 어려운 이용자가 도우미를 찾고, 희망 좌석과 예매 성공 조건을 전달한 뒤 결과와 증빙까지 확인할 수 있도록 설계했습니다.

## 주요 흐름

1. **도우미 탐색** — 프로필과 경력 정보를 보고 예매를 맡길 도우미를 찾습니다.
2. **요청 및 조건 합의** — 예매처, 희망 좌석, 성공 조건을 요청서에 담아 보내고 도우미와 최종 조건을 조율합니다.
3. **예매 결과 확인** — 도우미가 등록한 예매 결과와 증빙을 확인합니다. 필요한 경우 문의나 분쟁 절차로 이어집니다.

## 내 기여

### 개발

- **매칭 백엔드 개발** · Spring Boot로 도우미 프로필과 검색, 견적 요청, 매칭, 최종 조건 합의 API를 구현했습니다. 공연예술통합전산망(KOPIS) API를 연동해 실제 공연 정보를 서비스에서 조회할 수 있도록 했습니다.
- **AI 검토 기능 개발** · Liner AI로 도우미가 제출한 경력 설명과 증빙 사진을 비교하고, 내용이 일치하지 않거나 판단이 어려운 항목을 관리자에게 표시했습니다. 예매 요청서 검사와 도우미 사전 심사에도 AI를 연동했으며, 사전 심사의 최종 승인 권한은 관리자에게 두었습니다.
- **DB 변경 관리와 출시 후 개선** · Flyway를 도입해 DB 스키마 변경 이력을 버전별로 관리했습니다. 출시 후에는 검색 오류를 수정해 PR을 올리고 팀원과 배포 반영을 조율했습니다.

### 출시 준비 및 운영

- **법률 자문과 도우미 모집** · 출시 전 결제 심사, 이용약관, 분쟁 처리에 관한 질문을 정리해 후속 법률 자문을 요청했습니다. 출시 후에는 현업 도우미에게 직접 연락하고, 기존 거래 경험을 PICO 프로필에 보여줄 수 있도록 제출할 자료를 안내했습니다.

## 구현 및 데모

팀 프론트엔드는 React, TypeScript, Vite로 구성되며, OpenAPI 명세를 기준으로 백엔드 API와 연동합니다. 개발용 데모 모드에서는 결제와 본인인증 등 일부 단계의 응답을 모의 처리합니다.
